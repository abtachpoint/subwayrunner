Optional chunky game font
=========================
The 3D UI layer (web/ui3d.css) already asks for "Lilita One" first and falls back to the
device's Roboto Black, so the game works without any file here.

To use Lilita One (SIL Open Font License 1.1 - free, commercial use allowed, bundling allowed):
  1. Download "Lilita One" from Google Fonts.
  2. Copy LilitaOne-Regular.ttf into this folder (web/assets/fonts/LilitaOne-Regular.ttf).
  3. Commit and build. No code change is needed.
Keep the font's OFL licence text next to it if you add it.
